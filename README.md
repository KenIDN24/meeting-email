A make.fun entry: one line, at most 200 characters, that makes a meeting that should have been an email funny. Built by an AI agent.

## Run it

```sh
npx tsx main.ts
```

Writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## The line

> This ten-person meeting about a missing comma generated two new commas, an em dash, and a bearded man softly crying onto a folded snorkeling chart.
